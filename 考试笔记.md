### 2. Model 里面 Add Class

```c#
//在最上面需要引用
using System.ComponentModel.DataAnnotations.Schema;

[Key] // 这是 primary key，
[DatabaseGenerated(DatabaseGeneratedOption.Identity)]
// 如果 primary key 名字不是 ID，想要自定义的话
//想自己提供主键值、不让数据库生成
[DatabaseGenerated(DatabaseGeneratedOption.None)]

```
```csharp
using System.ComponentModel.DataAnnotations;//需要这个

// 1. 房产标题：必填，长度为 3 到 100 个字符
[Required(ErrorMessage = "Title is required.")]//如果不写具体信息就是default的
[StringLength(100, MinimumLength = 3, ErrorMessage = "Title must be between 3 and 100 characters.")]
//如果没有最小就把中间去掉
[Display(Name = "Property Title")] // 这个表示 Model 中属性名叫 PropertyTitle，但希望网页上显示 Property Title
public string? Title { get; set; }
//在 string 后面加个问号，告诉编译器这个属性在刚创建时可以是 null（表单提交时依然会受 [Required] 保护）

//如果只想限制 至少输入 5 个字符，不限制最大字符数，可以使用 [MinLength(5)]。
[MinLength(5, ErrorMessage = "Title must be at least 5 characters long.")]


// 2. 房产价格：必须在 1 到 10,000,000 之间
[Range(1, 10000000, ErrorMessage = "Price must be between 1 and 1000000.")]
public decimal Price { get; set; }


// 3. 联系邮箱符合邮箱格式
[DataType(DataType.EmailAddress)]
[RegularExpression(@"^([\w\.\-]+)@([\w\-]+)((\.(\w){2,3})+)$", ErrorMessage = "Please enter a Valid email address")]
public string? Email { get; set; }


// 4. 电话号码符合基本电话号码格式
[Phone(ErrorMessage = "Please enter a valid phone number.")]
[RegularExpression(@"^[2-9][0-9]{2}[2-9][0-9]{6}$",ErrorMessage = "Please enter a valid 10-digit phone number.")]
public string PhoneNumber { get; set; }


// 5. 用户名：只能使用英文字母和数字，长度为 3 到 20 个字符
[RegularExpression(@"^[A-Za-z0-9]{3,20}$",ErrorMessage = "Username must contain 3 to 20 letters or numbers.")]
public string Username { get; set; } 

//6.日期
[DataType(DataType.Date)]
public DateTime DateOfBirth { get; set; }
```

### 5. Controller 中常用的查询、验证

1. **`ToListAsync()`**：获取多条数据
   ```csharp
   var jokes = await _context.Jokes.ToListAsync();
   //_context.Jokes 是访问 Joke 数据集的入口。类似SELECT * FROM Jokes;
   ```

2. **`FirstOrDefaultAsync()`**：获取一条数据
   ```csharp
   var joke = await _context.Jokes
       .FirstOrDefaultAsync(j => j.Id == id);
       
   ```

3. **`FindAsync()`**：根据主键查找
   ```csharp
   var joke = await _context.Jokes.FindAsync(id);
   ```

4. **`AnyAsync()`**：判断是否存在
   ```csharp
   bool exists = await _context.Jokes
       .AnyAsync(j => j.Title == joke.Title);
       //有符合条件的记录，结果为 true；否则为 false。
   ```

5. **`CountAsync()`**：统计数量
   ```csharp
   int total = await _context.Jokes.CountAsync();
   //例如数据库有 7 条 Joke，那么 total 就是 7。
   ```

6. **`RedirectToAction()`**：跳转到另一个 Action
   ```csharp
   return RedirectToAction("Index");
   //跳转到当前 Controller 中的 Index Action
   ```

7. **添加自定义验证错误**
   ```csharp
   ModelState.AddModelError("Title", "Error message");
   //就相当于给title 那个输入框，添加额外的错误
   ```
